你画我猜

在线房间最多 8 人：1 人画、其余人抢答。第一个猜对的人得分，然后按顺序轮换画手。

玩法：画手看词作画，笔迹实时同步到所有人屏幕；任何人猜测都会立即判定对错，全体可见 ✓ / ✗。第一个猜对的人获胜得分，2 秒后轮换下一位画手；超时公布答案再轮换。
答案只在画手本机，猜手只看到字数提示；画手可换色、调笔刷粗细、用白色橡皮、清屏或换词。
中途加入的人会在下一局自动参与。离线/热点模式为 2 人对玩。

海龟汤

你将成为汤主（持答案）。好友提问，你只能回答：是 / 否 / 无关 / 是也不是。目标让好友还原故事。

玩法：系统随机抽一道经典海龟汤。汤主可点「查看汤底」读到完整故事（仅自己可见），喝汤人通过是非题逐步还原。回答会自动标注对应第几个问题；汤主也可发文字提示。
猜不出时由汤主「揭晓答案」，双方同时看到汤底，本局结束。

谁是卧底

3~8 人在线房间：每人私密拿到一个词，卧底拿到相近的另一个词。轮流一句话描述，再投票找出卧底。

玩法：系统随机抽一组相近词对，只有你自己能看到自己的词。按座位顺序每人用一句话描述（不能直接说出词），全部描述完后投票，得票最多者出局并公开身份；平票则无人出局。卧底全被找出则好人胜，卧底占到存活人数半数及以上则卧底胜。房主可随时「提前揭晓」。
中途加入的朋友，点「再来一局」即可一起玩。

传画接龙

3~8 人：每人先写一句开头，然后写 → 画 → 猜按座位依次传递，每人只看到上一步，最后逐本回放「原意怎么跑偏」。

玩法：每人写一句开头 → 传给下一位画出来 → 再传给下一位写下猜到的话 → 如此交替若干轮。每一步只给你看上一个人的内容，看不到更早的。全部完成后按顺序逐本回放整条链，看看最初那句话被传成了什么。
画作以笔迹数据传递，回放时可逐帧查看；中途加入的朋友，点「再来一局」即可一起玩。
